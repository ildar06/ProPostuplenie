## Установка и запуск

1. Установите зависимости в командную строку
   ```bash
   pip install -r requirements.txt 
   cd /d "Расположение программы на компьютере"

   ```
2. Запустите бота:
   ```bash
   python bot.py
   ```
3. Откройте бота в Telegram и отправьте `/start`.

## Задача

Абитуриенту нужен не ещё один список университетов, а понятный маршрут: куда
поступать, почему это подходит именно ему и что делать следующим шагом. Мы
сузили аудиторию до **выпускников школ Казахстана, поступающих на
бакалавриат** (одна страна, один уровень образования — в рамках допущений
кейса).

## Решение

Telegram-бот проводит пользователя по полному сценарию:

1. **Вход** (`/start`) — объяснение ценности и результата.
2. **Анкета** (6 шагов) — класс, интересы, балл ЕНТ, языки, бюджет, город.
3. **Диагностика** — краткое резюме профиля: сильные стороны и ограничения.
4. **Рекомендации** — минимум 3 программы с объяснением «почему подходит»
   (rule-based скоринг по интересам, ЕНТ, бюджету, городу, языку — без
   выдуманных гарантий).
5. **Сравнение** — любые 2 рекомендованных варианта бок о бок по ключевым
   параметрам.
6. **Roadmap** — персональный план: экзамены, документы, дедлайны,
   подготовка гранта.
7. **Следующий шаг** — один выделенный ближайший шаг с кнопкой «отметить
   выполненным»; прогресс сохраняется между сессиями.

Изменение любого ключевого ответа (кнопка «✏️ Изменить анкету») пересчитывает
рекомендации и roadmap заново — это отдельно проверено (см. тестовый сценарий).

## Стек

- **Python 3.10+**
- **python-telegram-bot 21.x** (async, `ConversationHandler` + `CallbackQueryHandler`)
- **SQLite** (стандартная библиотека `sqlite3`) — хранение профиля,
  рекомендаций и прогресса по roadmap между сообщениями/сессиями
- Никакого внешнего LLM/API не требуется — вся логика rule-based (это прямо
  разрешено условиями кейса). Объяснения рекомендаций собираются из реальных
  совпадений с анкетой, а не генерируются моделью.

## Архитектура

```
admission-bot/
├── bot.py        # хендлеры Telegram, ConversationHandler, весь UX-путь
├── data.py       # демо-датасет из 10 вузов/программ КЗ + справочники анкеты
├── scoring.py    # rule-based скоринг рекомендаций + генерация roadmap
├── db.py         # SQLite-хранилище (профиль, рекомендации, прогресс)
├── requirements.txt
├── .env.example
└── README.md
```

Состояния диалога: `GRADE → INTERESTS → ENT → LANGUAGES → BUDGET → CITY → MENU`.
Из `MENU` доступны рекомендации, сравнение, roadmap, прогресс и повторное
прохождение анкеты — без тупиков, всегда есть кнопка «что дальше».

## Данные о вузах — важное ограничение

Датасет в `data.py` (10 вузов Казахстана: NU, КБТУ, SDU, КазНУ, AlmaU,
КазНМУ, Satbayev, KIMEP, Turan, Narxoz) собран вручную для демонстрации.
**Пороги ЕНТ, стоимость обучения и дедлайны — демонстрационные данные**,
явно помечены в интерфейсе и не являются точной или гарантированной
информацией. Перед подачей документов пользователю нужно свериться с
официальным сайтом вуза (ссылка есть в каждой рекомендации). Бот нигде не
обещает гарантию поступления.

## Тестовый сценарий (для проверки жюри)

1. Отправьте `/start`, пройдите анкету полностью (класс → интересы → ЕНТ →
   языки → бюджет → город).
2. Убедитесь, что появилась диагностика и **минимум 3** рекомендации с
   пояснением «почему подходит» и демо-пометкой источника.
3. Нажмите «⚖️ Сравнить 2 варианта», выберите два вуза — должна появиться
   таблица сравнения по городу, порогу ЕНТ, стоимости, дедлайну, стипендиям.
4. Нажмите «🗺 Мой roadmap» — появится список шагов с одним выделенным
   «ближайшим шагом» и кнопкой «отметить выполненным».
5. Отметьте шаг выполненным — прогресс сохранится (проверить: перезапустить
   бота и открыть «✅ Прогресс» — отметка должна сохраниться, т.к. состояние
   лежит в SQLite, а не в памяти процесса).
6. Нажмите «✏️ Изменить анкету», измените **бюджет** или **город**,
   пройдите анкету заново — список рекомендаций и roadmap должны заметно
   измениться (проверено также автоматическим тестом логики, см. ниже).
7. Проверьте на мобильном клиенте Telegram — интерфейс полностью на
   inline-кнопках, ломаться не должен.

Быстрая проверка одной только логики скоринга без запуска бота:
```bash
python3 -c "
from scoring import compute_recommendations
p = {'interests': ['it'], 'ent_score': 90, 'languages': ['ru'], 'budget': 'mid', 'city': 'Алматы'}
for r in compute_recommendations(p):
    print(r['id'], r['score'], r['reasons'])
"
```

## AI / API

В текущей версии внешний AI/LLM API не используется — рекомендации и
объяснения полностью rule-based и детерминированы (это соответствует
разрешённому условиями кейса подходу и упрощает воспроизводимость для
жюри). Возможное расширение — см. ниже.

## Ограничения прототипа

- Один регион (Казахстан) и один уровень образования (бакалавриат) — по
  допущению кейса.
- Датасет вузов статичный и демонстрационный (10 записей), не подключён к
  реальным источникам данных в реальном времени.
- Нет отдельного экрана «эссе» и подбора стипендий вне грантовых заметок по
  вузу — оставлено как направление для доработки.
- Хранение данных — локальный SQLite-файл, подходит для демо и одного
  инстанса бота (не для промышленной нагрузки).

## Что расширить в первую очередь

1. **Подключить реальные источники** — парсинг официальных сайтов вузов или
   API приёмных комиссий вместо статичного `data.py`, чтобы пороги ЕНТ и
   дедлайны были актуальными, а не демо.
2. **LLM-слой поверх rule-based скоринга** — использовать существующие
   объяснения (`reasons`) как факты и попросить LLM переформулировать их в
   более персональный, разговорный текст (сохраняя проверяемость: LLM не
   придумывает цифры, а только переформулирует уже посчитанные факты).
3. **Оценка шансов поступления** — вероятностная модель на основе балла ЕНТ
   относительно исторического конкурса (если появятся реальные данные).
4. **Многопользовательская нагрузка** — перейти с SQLite на Postgres при
   росте числа пользователей, добавить веб-версию (Mini App) поверх той же
   логики `scoring.py`/`data.py`, чтобы не дублировать бизнес-логику.
5. **Активности и эссе** — модуль с рекомендациями олимпиад/проектов под
   выбранное направление и помощник по мотивационному письму.
